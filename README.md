🧠 GroupWise
Task & Group Divider/Assigner | Built in Pure Python with Tkinter UI

GroupWise is a lightweight desktop tool designed to help users efficiently organize and assign tasks among groups or individuals. It features an intuitive Tkinter-based interface, making task management simple even for non-technical users.

🚀 Features

📋 Task Assignment: Quickly assign tasks to members or groups.

🎲 Randomizer Option: Automatically randomize task distribution.

💾 JSON Save & Load: Persist task lists and group assignments for later use.

⚙️ Error Handling: Prevents empty or duplicate entries.

🧩 Resizable Interface: Flexible and user-friendly layout.

💻 Lightweight & Pure Python: No external dependencies beyond Tkinter.

🖥️ Tech Stack

Language: Python

UI Framework: Tkinter / customTkinter

⚠️ Requirements

Install dependencies before running:

pip install Pillow

pip install customtkinter

pip install tkcalendar
